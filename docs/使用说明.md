# 引脚网络重排 · 使用说明

在 PCB 中选中要交换的网络，自动求解最优的引脚-网络分配，使鼠线交叉与总线长最小——把"手工逐个调网络适配布线"变成一键求解。

## 解决什么问题

把 MCU/FPGA 的 IO 拉到排插或互连，是开发板与模块设计的常规操作。布局完成后，器件引脚
顺序与另一侧焊盘的鼠线经常大面积交叉，以往只能手工逐个调整某一侧的网络分配去适配布线，
费时且容易顾此失彼。

本插件把这一步建模为"器件引脚位置 ↔ 网络"的**指派问题**（匈牙利算法求最优解 + 2-opt
真实目标精修），目标 = 鼠线交叉数与总线长加权最小。支持排插 / MCU / FPGA 任意一侧作为
实施器件——在预览窗里点选即可。

## 工作流程

1. **选中网络**：在 PCB 中点选/框选要交换的网络（走线或焊盘）；
2. **菜单「交换选中网络」**：预览窗列出这些网络连接的器件及各自方案（每脚新旧网络、
   前后交叉数/鼠线总长、锁定原因）；
3. **应用**：直接改写所选器件的焊盘网络并保存，PCB 页签自动重开、鼠线即时可见
   （**真鼠线即预览**）；
4. **收尾**：满意 →「同步到原理图」（引脚独占导线自动改网络，其余列手工清单）；
   不满意 →「撤销上次交换」一键恢复。

## 重要：自动保存与备份

- **应用 / 撤销会自动保存 PCB，同步会自动保存原理图**；写操作完成后会**自动重新加载
  PCB 页签**（画布与鼠线即时重建，属正常现象）。
- 插件自带「撤销上次交换」（按台账恢复焊盘与导线网络），但改网络属批量写操作，
  **建议先对工程备份**再执行。

## 安全机制

- 交换只发生在选中的网络集合内部，器件其它引脚不受影响；
- 电源/地脚默认按名单自动锁定（3V3/1V8 等裸电压形态自动识别），任意引脚可在设置中锁定；
- 原理图自动同步只改"引脚独占导线"，汇入结点/电源符号承载的引脚列入手工清单而不是误改；
- 全程可撤销（含已同步的情况）。

## 安装

嘉立创EDA专业版 → 扩展 → 扩展管理 → 扩展上传，选择 `lceda-sch-header-swap_vX.Y.Z.eext`。

在 V3.2.149 实机开发验证；写路径按 V3.2 形态适配（焊盘经器件引脚对象写入，写后自动
重开 PCB 页签重建画布）。
